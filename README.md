# Spacex Launch Analysis

SpaceX launch analysis and prediction platform: data cleaning, exploratory analysis, a launch-site map, a correlation heatmap, and a model that predicts launch success. Includes the project report (PDF).

**Tech:** Python, Pandas, scikit-learn, Folium, Streamlit

## Run it

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

API keys are read from environment variables. Copy `.env.example` to `.env` and fill in your own keys.
